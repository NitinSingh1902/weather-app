# 🌦️ SkyCast – Weather App

SkyCast is a responsive weather application built using **HTML, CSS, and JavaScript**. It provides real-time weather information, hourly forecasts, and a 7-day weather forecast for different locations.

## ✨ Features

- 🔍 **Search by City** – Get weather information for any supported city.
- 📍 **Current Location** – Fetch weather using your device's location.
- 🌡️ **Temperature Toggle** – Switch between Celsius and Fahrenheit.
- 🌤️ **Current Weather** – View temperature, humidity, wind speed, UV index, and more.
- 🕒 **Hourly Forecast** – Check upcoming hourly weather conditions.
- 📅 **7-Day Forecast** – View weather predictions for the next seven days.
- 🌅 **Sunrise & Sunset** – Check daily sunrise and sunset times.
- 🌙 **Day/Night Theme** – Switch themes based on preference and weather conditions.
- 🌧️ **Rain Notifications** – Enable rain alerts and desktop notifications.
- 📱 **Responsive Design** – Enjoy a clean interface across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo API
- BigDataCloud Reverse Geocoding API
- Browser Geolocation API
- Web Notifications API
- Local Storage

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `weather.html` in your browser.
4. Allow location access if you want to check the weather for your current location.

No API key is required for the Open-Meteo weather API.

- **BigDataCloud API** – Helps identify the city and country from geographic coordinates.
